# Simple Git Demo Project

A tiny project used to practice a real git workflow: two people working on
different features in separate branches, then comparing and merging them.

## Branches in this repo

- `main` — the base page (title + placeholder comments for header/footer)
- `feature/navbar` — "Alice's" branch, adds a navigation bar
- `feature/footer` — "Bob's" branch, adds a footer

See the accompanying guide for how to push this to GitHub and how to
compare/merge the branches in VS Code.
